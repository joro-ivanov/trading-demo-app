# wiremock-ws-spike

This module is a focused proof-of-concept around WireMock's WebSocket beta support.

Its role in the repository is to validate and demonstrate test techniques, not to provide
production application behavior.

## Quality Boundary

- The code here is **demo/proof-of-concept code**.
- The tests are the important part and are expected to be **production-grade examples** of how to
  exercise fault injection and WS behavior.

For the overall suite map, see [`../docs/test-coverage.md`](../docs/test-coverage.md).
